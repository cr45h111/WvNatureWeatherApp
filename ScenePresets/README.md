# Scene Presets

This folder contains pre-made scene configurations for the WV Nature & Weather app. These presets can be loaded to quickly set up beautiful nature scenes with specific themes and compositions.

## What are Scene Presets?

Scene presets are JSON files that define:
- Item types and placements (trees, plants, animals, signs)
- Terrain configurations
- Scene descriptions and metadata

## Using Presets

To use these presets in the app:
1. Open the **🏪 Store** menu
2. Scroll to **🎨 Scene Presets** section
3. Click any preset to load it into your scene

## Available Presets

See `scene-presets.json` for all available preset configurations.

## Creating Your Own

You can create your own presets by:
1. Building a scene in the app
2. Opening **⚡ Quick Actions**
3. Clicking **🎨 Save as Preset**
4. Giving it a name and description

Your custom presets are saved in your browser's localStorage and can be exported using the `export-presets.html` tool in the project root.
